Permintaan Penghapusan Data - MediCare

Aplikasi MediCare tidak menggunakan sistem akun atau login. Seluruh data tersimpan secara lokal di perangkat Anda dan tidak dikirim ke server manapun.

Cara menghapus seluruh data MediCare:
  1. Buka Pengaturan HP Anda
  2. Pilih Aplikasi / Manajemen Aplikasi
  3. Cari dan pilih MediCare
  4. Tap Hapus Data / Clear Data
  5. Konfirmasi penghapusan

Semua data aplikasi akan terhapus permanen dari perangkat Anda.

Atau Anda dapat menghapus aplikasi sepenuhnya untuk menghapus semua data terkait.
